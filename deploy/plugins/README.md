# M3TAL Plugin Declarations Directory

Legacy bundled plugins have been purged from this directory as part of the plugin standardization initiative.
See [plans/plugin/standardization_spec.md](../../plans/plugin/standardization_spec.md) and [plans/plugin/inventory_and_roadmap.md](../../plans/plugin/inventory_and_roadmap.md).

All plugin code, manifests, and UI bundles now live self-contained within each respective plugin repository or package (`m3tal-<plugin-name>`).
